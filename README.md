# 📱 FlashFeed

**FlashFeed** is a smart, real-time news aggregation app that delivers the latest headlines using the **GNews API**, reads them aloud using **Text-to-Speech (TTS)**, and presents quick, AI-powered news summaries for users who are always on the go.

---

## 🚀 Features

- 🔍 **Real-Time News Fetching**: Pulls the latest articles from reliable sources using the GNews API.
- 🧠 **AI News Summarization**: Converts lengthy news descriptions into concise summaries using BART NLP model.
- 🔊 **Text-to-Speech Support**: Reads out headlines and summaries for hands-free browsing.
- 🔗 **Share News**: Easily share news links with friends and family via social media or messaging apps.
- 📱 **Clean UI**: Sleek, minimal interface focused on user experience and readability.

---

## 🛠️ Tech Stack

- **Frontend**: Android (Java)
- **Backend/Services**:
  - [GNews API](https://gnews.io/)
  - [Hugging Face Transformers](https://huggingface.co/models) for summarization
  - Android **TextToSpeech (TTS)** engine
  - Firebase (for storage)
